# Video Capability Map

> Source: https://kling.ai/document-api/guides/capability-map/video
> Locale: en
> Updated At: 2026-05-19
> This content is optimized for LLMs. UI-only controls are omitted.

Organized from the existing Video Models document, showing model, mode, and capability support for video APIs.

## Models

| Model | Description | Input | Generation Range | Resolution |
| --- | --- | --- | --- | --- |
| Kling 3.0 Turbo | Consistently excellent results, with even better value. | Text, Image | 3~15s | 720P, 1080P |
| Kling 3.0 | Enhanced native audio, improved element consistency, and support for multi-shot storytelling | Text, Image, Video | 3~15s | 720P, 1080P, 4K |
| Kling 3.0 Omni | All-in-one multimodal input, voice-driven characters, and native audio output with storyboards | Text, Image, Video | 3~15s | 720P, 1080P, 4K |
| Kling O1 | Unified video model with all-in-one multimodal instructions and exceptional consistency. | Text, Image, Video | 3~10s | 720P, 1080P |
| Kling 2.6 | See the sound, hear the visual | Text, Image, Video | 3~10s | 720P, 1080P |
| Kling 2.5 Turbo | Max creativity with exceptional value | Text, Image | 5s, 10s | 720P, 1080P |

## Global Capabilities

| Capability | Value | Description |
| --- | --- | --- |
| Avatar | All model versions | Generate digital human broadcast-style videos with just one photo |
| Lip Sync | All model versions | Can be combined with text or audio to drive the mouth shape of characters in the video |
| Multi-element Video Editing | All model versions | Supports marking, replacing, and adding or removing elements in videos |
| Video to Audio | All model versions | Supports adding audio to all videos generated by Kling models and user-uploaded videos |
| Text to Audio | All model versions | Supports generating audio by text prompts |
