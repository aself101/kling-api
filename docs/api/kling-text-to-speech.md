## Create Task

### API Overview

- Method: `POST`
- Path: `/v1/audio/tts`
- Auth: `Authorization: Bearer <API_KEY>`
- Content-Type: `application/json`

### Description

Text-to-Speech synthesis API for generating audio from text.

### Headers

| Field | Type | Required | Default | Enum | Description |
|---|---|---:|---|---|---|
| `Content-Type` | string | Yes | `application/json` | - | Data Exchange Format |
| `Authorization` | string | Yes | - | - | Authentication information, refer to API authentication |

### Request Body

| Field Path | Type | Required | Default | Enum | Description |
|---|---|---:|---|---|---|
| `text` | string | Yes | - | - | Text Content for Audio Synthesis |
| `voice_id` | string | Yes | - | - | Voice ID |
| `voice_language` | string | Yes | `zh` | `zh`, `en` | Voice Language |
| `voice_speed` | float | No | `1.0` | - | Speech Rate |

#### Request Body Field Notes

- `text`: The maximum length of the text content is 1000 characters; content that is too long will return an error code and other information.
- `text`: The system will validate the text content; if there are issues, it will return an error code and other information.
- `voice_id`: The system offers a variety of voice options to choose from. For specific voice effects, voice IDs, and corresponding voice languages, see [Voice Guide](https://docs.qingque.cn/s/home/eZQDvafJ4vXQkP8T9ZPvmye8S?identityId=2E1MlYrrPk4). Voice previews do not support custom scripts.
- `voice_id`: Voice preview file naming convention: Voice Name#Voice ID#Voice Language
- `voice_language`: The voice language corresponds to the Voice ID, as detailed above.
- `voice_speed`: Valid range: [0.8, 2.0], accurate to one decimal place; values outside this range will be automatically rounded.

### Request Example

```bash
curl --request POST \
  --url https://api-singapore.klingai.com/v1/audio/tts \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "text": "Throughout my time in college, several memorable event left a significant impact on my life",
    "voice_id": "oversea_male1",
    "voice_language": "en",
    "voice_speed": 1
  }'
```
